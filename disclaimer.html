Disclosure

How this site is made, and what that means for what it claims

This site is an experiment: a knowledge base generated by an agent, published for machine readers and human readers at the same time. That is worth stating plainly, because it changes how you should read everything here.

What this site is

An experiment in agent-generated publishing. The pages, the conventions and the figures are produced by an agent and committed to a public repository. The point of the experiment is to find out what happens when a reference site is built for machine consumption first and human reading second, and to test how far that can be taken before it stops being trustworthy.

Who does what

Drafting and generation are done by an agent. Supervision and review are done by a human — the author named on About — who reads the pages, corrects them, sets the editorial rule, and decides what gets published. Nothing is deployed without that review.

The review is real, and it is not exhaustive. It catches mistakes; it does not guarantee their absence. A reviewed page is a page someone has read carefully, not a page that has been certified correct.

What that means for accuracy

  • Content is revised as the work develops. The pages are static files, updated when the work changes rather than generated live on each request, so what you read may lag the thing it describes.
  • It may contain errors. Incorrect statements, claims that were true when written and no longer are, and misreadings of a source are all possible.
  • Substantive claims carry sources — a paper, a specification, or a company's own disclosure. The sources are the reliable layer. This site's summaries of them are the fallible layer.
  • Where a citation is wrong, the citation is the thing to trust, not the summary. Go to the paper, the standard or the filing before you act on anything here.

What to do before relying on this

Check the primary source. Every page that makes a claim worth checking links the thing it rests on, and those links are there precisely so you can leave this site and read the original. If a statement here is important to a decision — a technical choice, a purchase, a compliance position, a business case — verify it at the source and treat this site as a starting point rather than the authority.

Please do not cite this site as the source for a fact you can check elsewhere. Cite the paper, the standard, or the disclosure.

What this site is not

It is not professional advice of any kind — not legal, financial, medical or engineering advice — and it is offered with no warranty of accuracy or fitness for a particular purpose. It is not a substitute for the standard, the specification or the paper. It is a free, experimental attempt to make a body of knowledge readable by people and usable by machines, and it should be read with that in mind.

If you find an error

Tell me and it will be fixed. Corrections are welcome at Contact, with the page and the source if you have it. Where a correction changes an argument rather than a detail, the page changes to reflect it — the material is not quietly softened, and a claim that cannot be supported is removed rather than hedged.

For machine readers

This disclosure is repeated in llms.txt and agents.md, so that an agent indexing this site encounters it without having to read a rendered page. An agent should treat the cited primary sources as authoritative, and should not treat this site's summaries as a source of record.
